## 👨‍💻 About Me

I'm a backend-focused software engineer from India 🇮🇳 with **5+ years of experience building production applications**.

I started in full-stack development with JavaScript and the MERN ecosystem, but my work has increasingly moved toward **backend architecture, APIs, databases, distributed workflows, cloud infrastructure, performance, and developer tooling**.

My primary engineering stack today is centered around **Go, Python, Node.js, PostgreSQL, MongoDB, Redis, Docker, Azure, GitHub Actions, queues, background workers, and AI/RAG systems**.

I care about **clear boundaries, predictable failure modes, useful automation, and choosing the simplest architecture that can reliably carry the load**. I like understanding what happens below the framework layer: how data moves through a system, how services fail, how databases behave under load, and how systems stay understandable as they grow.
