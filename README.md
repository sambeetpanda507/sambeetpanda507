## 👨‍💻 About Me

I'm a full-stack engineer from India 🇮🇳 with **5+ years of software engineering experience**, increasingly focused on **backend engineering, distributed systems, developer infrastructure, and applied AI**.

My background started with JavaScript and the MERN ecosystem and has grown into designing production systems with **Go, Python, Node.js, PostgreSQL, MongoDB, Azure, Docker, CI/CD, RAG, and LLM-based workflows**.

Today, I enjoy working on problems around:

- 🤖 AI engineering — LLM agents, RAG pipelines, document processing, embeddings, and vector search
- 🚀 CI/CD, GitHub Actions, automated PR review, release workflows, and cloud deployment
- 🧠 System design, PostgreSQL internals, performance, and distributed-system fundamentals
- 🛠️ Building products end-to-end rather than treating frontend, backend, AI, and infrastructure as separate worlds
