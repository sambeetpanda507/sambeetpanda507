## 👨‍💻 About Me

I'm a software engineer from India 🇮🇳 with **5+ years of experience building production applications**, with my current focus firmly on **backend engineering**.

I started in full-stack development with JavaScript and the MERN ecosystem, but over the years my work has moved increasingly toward **backend architecture, APIs, databases, distributed systems, cloud infrastructure, performance, and developer tooling**.

My primary engineering stack today is centered around **Go, Python, Node.js, PostgreSQL, MongoDB, Redis, Docker, Azure, GitHub Actions, queues, background workers, and AI/RAG systems**.

I care about understanding what happens below the framework layer: how data moves through a system, how services fail, how databases behave under load, how concurrency works, how APIs are secured, and how systems remain observable and maintainable as they scale.

---

## ⚙️ Backend Engineering

This is where I spend most of my engineering energy.

- **API & Service Design** — REST APIs, authentication, authorization, service boundaries, validation, error handling, versioning
- **Databases** — PostgreSQL, MongoDB, schema design, indexing, query optimization, transactions, materialized views, search, pgvector
- **Concurrency & Async Processing** — Go concurrency, Python async, background workers, RabbitMQ, event-driven workflows
- **Distributed Systems** — queues, retries, idempotency, caching, consistency, service-to-service communication, failure handling
- **Performance** — profiling, query tuning, caching, connection management, reducing latency and unnecessary I/O
- **Security** — JWT/refresh-token flows, signed requests, service authentication, secrets, access control
- **Infrastructure** — Docker, Azure Container Apps, Azure App Service, CI/CD, GitHub Actions, release automation
- **System Design** — scalability, reliability, observability, maintainability, low-level and high-level design
